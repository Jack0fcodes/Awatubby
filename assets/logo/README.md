# Circular logo GIF

The header brand mark uses this animated image:

`assets/logo/logo.gif`

To replace it:
1. Open https://github.com/Jack0fcodes/Awatubby/tree/main/assets/logo
2. Choose **Add file → Upload files**.
3. Upload your GIF named exactly `logo.gif`.
4. Commit to the `main` branch.

The image is cropped to a circle automatically. For best results, use a square GIF with the logo centered and a little padding around it. Replacing this file won't affect the hero or About GIFs.
