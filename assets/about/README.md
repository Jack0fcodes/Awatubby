# About section GIF

The About section displays this GIF:

`assets/about/about.gif`

## Replace it with your own animation

1. Open this folder on GitHub: https://github.com/Jack0fcodes/Awatubby/tree/main/assets/about
2. Click **Add file → Upload files**.
3. Upload your own GIF named exactly **about.gif**.
4. Commit the replacement to the **main** branch.

The website already uses this file path, so you don't need to edit `index.html`. The GIF is displayed inside the white rounded frame in the About section. Keep the file as a GIF and preserve the filename and folder.

The existing image is only a starter placeholder (currently a copy of the hero GIF). Replacing it will not affect the hero animation or any About text.
