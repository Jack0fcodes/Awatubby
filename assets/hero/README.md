# Hero GIF replacement

The portfolio's hero animation is loaded from:

`assets/hero/hero.gif`

## Replace it with your own higher-quality GIF

1. Open this folder in GitHub: https://github.com/Jack0fcodes/Awatubby/tree/main/assets/hero
2. Choose **Add file → Upload files**.
3. Upload your better-quality GIF and name it exactly **hero.gif**.
4. Commit the upload to the **main** branch. If GitHub asks whether to replace the existing file, confirm replacement.

The website already points to this exact file, so you do not need to edit `index.html`. Keep the file as a GIF and keep the path/name unchanged.

The two floating bubble captions (“made with ♡” and “little ideas, lots of love”) are HTML text layered separately over the image. Replacing this GIF will not remove or change those captions.

For a crisp result, export the animation from the original source at the intended display dimensions, use a high-quality GIF palette/dithering setting, and avoid repeatedly re-saving a compressed GIF. GitHub Pages will serve the replacement at the same path.
